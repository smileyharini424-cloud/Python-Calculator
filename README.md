# Python Calculator

## Explanation

This project is a simple calculator developed using Python. It accepts two numbers from the user and performs basic arithmetic operations.

## Problem Statement

Create a Python program that takes two numbers as input and performs addition, subtraction, multiplication, and division.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Handles division by zero
* Uses functions for each operation
* Accepts user input

## How It Works

1. The user enters the first number.
2. The user enters the second number.
3. The program performs four arithmetic operations.
4. The result of each operation is displayed.
5. If the second number is zero, division is handled safely.

## Technologies Used

* Python

## Data Structure Used

* No special data structure is required.

## Methods Used

* Functions
* User input
* Arithmetic operators
* Conditional statements

## Program Flow

1. Start the program.
2. Read two numbers.
3. Call the addition function.
4. Call the subtraction function.
5. Call the multiplication function.
6. Check whether the second number is zero.
7. Perform division if possible.
8. Display all results.
9. End the program.

## Sample Input

```text
Enter first number: 20
Enter second number: 5
```

## Sample Output

```text
Addition: 25.0
Subtraction: 15.0
Multiplication: 100.0
Division: 4.0
```
